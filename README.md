# Chess Python

A chess engine written in Python.

## Current Features

- Board representation
- Knight movement
- Bishop movement
- Rook movement
- Queen movement
- King movement
- Move generation
- Enpassant logic
- Castling logic

## In Progress
- Performance checking (no. legal_moves upto a certain depth from starting position)
- Stalemate detection
- Checkmate detection

## Project Structure

- `board.py` — represents the chess board and pieces
- `move_generation.py` — generates legal piece movements
- `main.py` — program entry point
